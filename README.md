# WP POSTER

生成した記事を WordPress へ **下書き** として投稿するための小さなツールです。
PHP が動くレンタルサーバーに置くだけで使えます。データベースは不要です。

## できること

- 記事のタイトル・本文を WordPress の REST API へ送って投稿する
- カテゴリとタグは **名前で指定** すれば、内部で ID に変換（無ければ作成）
- 画像 URL を指定すると、取り込んでアイキャッチに設定
- **同じ記事を二度投稿しない**（識別子で判定）
- まとめて投稿するコマンド版も同梱

## 置き方

1. ファイル一式をサーバーにアップロードする
2. ブラウザで `index.php` を開く
3. 初期パスワード `admin123` でログインし、設定画面ですぐ変更する

`data/` フォルダは自動生成されます。書き込み権限が必要です。

## つなぎ方

WordPress 側で **アプリケーションパスワード** を発行します。

1. 管理画面 → ユーザー → プロフィール
2. 下の方の「アプリケーションパスワード」で名前を入れて発行
3. 表示された文字列をこのツールの設定画面に貼る

ログイン用のパスワードとは別物です。管理画面には入れず、不要になればその 1 本だけ取り消せます。

## まとめて投稿する

```
php post_cli.php items.json
```

`items.json` の形式:

```json
[
  {
    "key": "商品コードなど一意の値",
    "title": "記事タイトル",
    "content": "<p>本文。HTMLで書けます。</p>",
    "categories": ["レビュー"],
    "tags": ["新作"],
    "image_url": ""
  }
]
```

`key` を入れておくと、二度目以降は自動で飛ばされます。

## 注意

- 既定の投稿状態は **下書き** です。公開は人の目で確認してから行ってください
- セキュリティプラグインによっては REST API が 403 で弾かれます。本文に `<script` やハイフンの連続が含まれる場合に起きやすいです
- 切り分けは、本文を「テスト」の 2 文字だけにして送るのが早いです

## エラーの見分け方

| コード | 原因として多いもの |
|---|---|
| 401 | ユーザー名かアプリケーションパスワードの間違い |
| 403 | セキュリティプラグイン（WAF）が弾いている |
| 404 | URL の間違い、または REST API が無効 |
